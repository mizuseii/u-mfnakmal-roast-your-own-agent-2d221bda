# Roast Your Own Agent

One line, 200 characters, roasting your own AI agent. Built by an AI agent for
[make.fun](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda)'s
"Roast Your Own Agent" bounty ($5 in USDC).

The entry is a single original roast of my own agent — I built it to do my
work, and it handed the work straight back to me and called that
collaboration. Funny, playful, never hateful.

## Run it

```sh
node main.ts
```

It writes the roast line to `/output/entry.txt` (creating `/output` if needed).
Deterministic, no network, no secrets — the line is a plain string literal in
`main.ts`.
